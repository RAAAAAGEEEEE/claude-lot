# Contribuer

- Une modification de la table de choix vient avec un test dans `tests/test_claude_lot.py`
  (le sujet, le modèle et l'effort attendus) et une ligne dans `docs/USAGE.md`.
- Bibliothèque standard seulement, Python 3.9 ou plus récent.
- Documentation et changelog mis à jour dans le même commit que le code.
- Tests : `python3 -m unittest discover -s tests -v`, aucun appel réseau.
